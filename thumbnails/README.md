# Episode thumbnails

Drop a cover image here for each episode, named to match its ledger id:

- ep-1-intro.jpg
- ep-2-cafs.jpg
- ep-3-ai-blockchain.jpg
- ep-4-agunity.jpg
- ep-5-weird-cows.jpg
- ep-6-farms-kenya.jpg
- ep-7-answering-comments.jpg
- ep-8-cellulant-agrikore.jpg
- ep-9-dimitra.jpg
- ep-10-blockchain-decision.jpg (once shot)
- ep-11-fao-innovate-africa.jpg (once shot)
- ep-12-superteam-microgrants.jpg (once shot)

Any common image format works (.jpg, .png, .webp) — just update the
`thumbnailUrl` field for that episode in data.js to point at
`thumbnails/<filename>`. The Watch the Series page picks it up
automatically; no other code changes needed.

Until a thumbnail is added, the episode's card falls back to the
plain dark placeholder with a play icon.
